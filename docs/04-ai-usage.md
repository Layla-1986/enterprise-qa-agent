# AI 使用与个人参与说明

## 个人参与和 AI 使用

- 候选人提供题目和卷面文件，参与方案设计和 AI 辅助代码生成，提出需求及修改要求，并在项目生成后参与审查、效果检查以及方案的改进和优化。
- Codex 协助生成和修改代码、合成资料、测试与文档，调用真实模型生成运行记录，并执行自动化测试及结果检查。
- 离线 Mock 用于验证程序流程，不能证明真实模型的决策能力；真实模型结果与失败记录见 `examples/`。

## 实际用时

约 2 小时 30 分钟（150 分钟），由候选人提供。

## 经验迁移

本次工作结合了此前对工业知识问答、检索评估和 Agent 流程的学习。以往项目中的框架、模型和评测结果不自动代表本项目的实现或验证结果。
