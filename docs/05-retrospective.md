# 复盘

## 最难的问题

企业制度可能同时存在不同规定。检索命中本身不能证明某条制度适用，因此需要读取原文并检查是否存在冲突；缺少适用范围和优先级时，应呈现不同依据并请求确认，而不是仅依据日期选择答案。

## 可结合既有学习经验理解的收获（提交前本人核对）

1. **检索与证据是不同环节。** 结合此前对知识检索与检索评估的学习，可以理解为什么本项目先检索、再读原文、最后检查引用；逐字引用检查也不等于已经证明回答在语义上正确。
2. **Agent 决策需要观察工具结果。** 本项目让模型选择检索、读取或结束，并把工具结果送回模型；结合之前对 Agent 流程的学习，可以比较这种循环与固定条件分支的区别。
3. **评价要覆盖失败和资料变化。** 不仅检查正常答案，也要检查冲突、资料不足、工具失败、追问和修改资料后的结果，并保留模型格式错误等失败记录。

以上是根据以往相关学习方向和本项目实现整理的复盘草稿，是否符合本人实际理解需由候选人确认，不应直接视为本人独立完成或掌握的证明。

## 已知限制与下一步

当前字符检索可能遗漏相关资料；原文子串校验不能证明语义支持；模型输出偶发格式错误。可继续构建标注测试集，评估召回与误答，改进检索和重排，并研究语义支持校验、权限隔离及提示注入防护。
